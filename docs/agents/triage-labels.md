# Triage Labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation required |
| needs-info | needs-info | More information required |
| ready-for-agent | ready-for-agent | Ready for autonomous agent work |
| ready-for-human | ready-for-human | Human work or judgement required |
| wontfix | wontfix | Will not be implemented |

When a skill names a triage role, use its mapped tracker label.
Reuse existing labels rather than creating duplicates.
